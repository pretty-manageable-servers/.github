# PMServers

Cloud infrastructure with a unified console, command line interface, and API.

> [!WARNING]
> **This entire project was built as a joke. Do not use it.**
>
> Nothing in this organization should be relied on for production, real workloads, or sensitive data. There are no guarantees of security, reliability, or support.

## Platform

PMServers brings virtual machines, containers, databases, and AI API access into a project-based management interface. The web console and `pms` CLI provide interfaces for managing resources, access, and credentials.

## Open source

We publish selected platform components here, including our client tools, authentication service, and documentation.

| Repository | Component |
| --- | --- |
| [pmservers-cli](https://github.com/pretty-manageable-servers/pmservers-cli) | The `pms` command line interface for managing cloud resources and project access. |
| [pmservers-dashboard](https://github.com/pretty-manageable-servers/pmservers-dashboard) | The web console for managing platform resources. |
| [pmservers-auth](https://github.com/pretty-manageable-servers/pmservers-auth) | Device authorization service for CLI sign-in. |
| [pmservers-docs](https://github.com/pretty-manageable-servers/pmservers-docs) | Platform documentation and API reference. |

See [docs.pmservers.org](https://docs.pmservers.org) for platform concepts, interfaces, and configuration details.
